## Cara Menambah Game Baru

1. Buat folder baru di dalam `games/`, misalnya `games/nama-game-baru/`.
2. Simpan kode HTML game sebagai `index.html` di folder itu.
3. Tambahkan satu kartu baru di `index.html` portal (halaman utama) yang menaut ke folder game baru tersebut.
4. Tambahkan baris baru pada tabel Daftar Game di README ini.

Portalnya tetap sama — game baru cukup ditambahkan sebagai kartu dan folder baru, tanpa mengubah game yang sudah ada.
